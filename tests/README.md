# Tests And Evaluations

This folder contains human-readable evaluation material for checking whether a skill improves agent behavior.

These are not unit tests for a library. They are review aids for prompts, examples, and generated outputs.

## What To Evaluate

- Does the skill trigger on the right task?
- Does the agent inspect relevant code or context first?
- Does it identify the real architecture pressure?
- Does it choose the smallest useful structure?
- Does it avoid unnecessary patterns or abstractions?
- Does it include verification steps?

## Evaluation Types

- `skill-output-format.md`: expected sections and output shape.
- `example-evaluation-checklist.md`: checklist for before/after examples.
- Future files may include prompt suites for specific skills.
