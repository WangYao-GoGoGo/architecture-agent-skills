# Platform Skills

Platform skills review systems whose architecture depends on external ecosystems: WeChat, bot platforms, cloud accounts, IoT devices, Pepper/NAOqi, robot arms, industrial controllers, and other vendor-owned runtimes.

- `platform-ecosystem-architecture-review/`: generic external-platform boundary review.
- `wechat/wechat-mini-program-architecture/`: WeChat mini program structure and platform integration review.
- `robotics/robotics-platform-architecture/`: robotics platform, robot arm, Pepper/NAOqi, and hardware integration review.
