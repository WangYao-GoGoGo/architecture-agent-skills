# OO Design Pattern Selector

Use this skill for OO-specific pattern choices. For broader cross-paradigm selection, use the core design-pattern-selector.

## Workflow

1. Identify the design pressure: variation, creation, integration, notification, command, workflow, or subsystem boundary.
2. Check whether simple OO code is enough.
3. Select at most one primary pattern.
4. Keep interfaces small and close to the consumer.
5. State rejected alternatives.

## Output Format

```markdown
OO pattern recommendation:
- Pressure:
- Pattern:
- Why it fits:
- Simpler alternative:
- Refactoring steps:
```
