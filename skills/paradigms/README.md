# Paradigm Skills

Skills for reasoning about code structure based on programming paradigm.

## Available Paradigm Packs

- [`object-oriented/`](object-oriented/) — responsibility assignment, polymorphism, encapsulation, SOLID, GRASP, design patterns
- [`procedural/`](procedural/) — modular procedural design, data ownership, side-effect boundaries, interface discipline
- [`functional/`](functional/) — pure functions, immutability, composition, algebraic data types
- [`systems/`](systems/) — systems boundary design, resource ownership, error handling, concurrency

## When To Use Paradigm Skills

Use paradigm skills when the main architectural question is about **how code should be structured** according to a programming model, rather than which framework or language to use.

- **Object-oriented**: domain concepts with behavior and invariants, polymorphism for variation, encapsulated mutable state
- **Procedural**: straightforward workflows, C-style modules, scripts, data transformations
- **Functional**: data pipelines, concurrency-safe transformations, business rules as pure logic
- **Systems**: resource-constrained environments, embedded systems, performance-critical paths
