# Data Modeling Review

## Workflow

1. Identify entities, aggregates, documents, or records and their owners.
2. List read and write access patterns.
3. Check normalization, denormalization, duplication, and update consistency.
4. Review cardinality, lifecycle, retention, and migration impact.
5. Recommend a model shape with tradeoffs.
