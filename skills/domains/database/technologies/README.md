# Database Technology Skills

Technology-specific database skills live here when guidance depends on a specific database engine.

## Relational Databases

- [`mysql/`](./mysql/) — MySQL-specific skills for query plans, indexes, transactions, locks, schema design, and migration risks.
- [`postgresql/`](./postgresql/) — PostgreSQL-specific skills for query plans, indexes, constraints, JSONB, full-text search, transactions, and migrations.
- [`oracle/`](./oracle/) — Oracle-specific skills for query plans, indexes, partitions, PL/SQL, RAC, and performance tuning.
- [`sql-server/`](./sql-server/) — SQL Server-specific skills for query plans, indexes, T-SQL, SSIS, and high availability.
- [`sqlite/`](./sqlite/) — SQLite-specific skills for embedded schema design, WAL mode, concurrency, and migration strategies.
- [`mariadb/`](./mariadb/) — MariaDB-specific skills for query optimization, storage engines, Galera clustering, and migration from MySQL.
- [`cockroachdb/`](./cockroachdb/) — CockroachDB-specific skills for distributed SQL, geo-partitioning, serializable isolation, and cluster topology.
- [`tidb/`](./tidb/) — TiDB-specific skills for HTAP workloads, distributed transactions, TiKV storage, and placement rules.
- [`timescaledb/`](./timescaledb/) — TimescaleDB-specific skills for hypertables, continuous aggregates, data retention, and time-series optimization.
