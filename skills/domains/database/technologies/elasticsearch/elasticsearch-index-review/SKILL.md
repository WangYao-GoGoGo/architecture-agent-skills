# Elasticsearch Index Review

## Workflow

1. Identify search, filter, sort, aggregation, and relevance requirements.
2. Review mappings, analyzers, keyword/text fields, nested objects, and date fields.
3. Check shard count, index lifecycle, reindexing, and storage growth.
4. Recommend mapping or index strategy changes.
5. Verify with example queries and relevance checks.

## Output Format

```markdown
Elasticsearch index review:
- Query requirements:
- Mapping/index issues:
- Shard/lifecycle risks:
- Recommendation:
- Verification:
```
