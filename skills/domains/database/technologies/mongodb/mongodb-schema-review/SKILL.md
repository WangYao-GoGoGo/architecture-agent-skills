# MongoDB Schema Review

## Workflow

1. Identify collections, documents, relationships, and access patterns.
2. Review embedding vs references, indexes, document growth, and update paths.
3. Check aggregation needs, shard key risks, and consistency expectations.
4. Recommend schema and index changes with migration impact.
5. Verify with representative queries and sample documents.

## Output Format

```markdown
MongoDB schema review:
- Collections/documents:
- Access patterns:
- Schema/index risks:
- Recommendation:
- Verification:
```
