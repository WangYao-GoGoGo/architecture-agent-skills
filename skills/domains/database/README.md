# Database Domain Skills

Skills for data modeling, indexing, migrations, transactions, caching, document modeling, graph modeling, search, and database-specific architecture.

## Categories

- [`core/`](./core/) — Cross-cutting database skills: data modeling, indexing, transactions, migrations, and architecture review.
- [`relational/`](./relational/) — Relational database skills: schema normalization, query review, and performance tuning.
- [`document/`](./document/) — Document database skills: document modeling, embedding vs references, and aggregation pipelines.
- [`key-value/`](./key-value/) — Key-value database skills: access pattern review, key design, and TTL strategies.
- [`graph/`](./graph/) — Graph database skills: graph modeling review and traversal optimization.
- [`column-family/`](./column-family/) — Wide-column database skills: column family modeling and row key design.
- [`search/`](./search/) — Search engine skills: relevance tuning, indexing strategy, and performance review.
- [`vector/`](./vector/) — Vector database skills: vector search architecture and embedding strategy.
- [`cache/`](./cache/) — Caching skills: cache invalidation, strategy selection, and Redis data structure review.
- [`technologies/`](./technologies/) — Technology-specific database skills for 30+ database engines.
