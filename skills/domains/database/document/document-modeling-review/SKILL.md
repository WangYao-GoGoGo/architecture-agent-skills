# Document Modeling Review

## Workflow

1. Identify documents, aggregates, references, and ownership.
2. Map read and write access patterns.
3. Check embedding vs referencing against update frequency and query needs.
4. Review duplication, consistency, document growth, and indexing.
5. Recommend a document shape with tradeoffs.

```markdown

- Access patterns:

- Risks:
```
