# Graph Modeling Review

## Workflow

1. Identify entities, relationships, properties, and traversal questions.
2. Check whether relationships are first-class domain facts.
3. Review cardinality, direction, uniqueness, and indexing.
4. Look for relational modeling forced into graph shape without traversal benefit.
5. Recommend model and query changes.
