# Pipeline Architecture Review

## Workflow

1. Map sources, transformations, sinks, schedules, and ownership.
2. Identify data contracts and schema evolution points.
3. Check idempotency, retries, backfills, ordering, and late data handling.
4. Review validation, observability, and failure recovery.
5. Recommend boundary or stage changes.
