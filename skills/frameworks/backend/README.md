# Backend Framework Skills

Backend framework-specific skills live here when architecture depends on request lifecycle, routing, dependency injection, validation, persistence boundaries, background jobs, configuration, and observability.

## Java / JVM

- [`spring-boot/`](./spring-boot/) — Spring Boot: auto-configuration, bean lifecycle, transaction boundaries, actuator, profiles.
- [`micronaut/`](./micronaut/) — Micronaut: AOT compilation, DI, reactive streams, HTTP routing, GraalVM native-image.
- [`quarkus/`](./quarkus/) — Quarkus: CDI beans, reactive messaging, Panache ORM, extensions, native-image.
- [`vertx/`](./vertx/) — Vert.x: verticle architecture, event bus, reactive streams, shared data, async coordination.
- [`play/`](./play/) — Play Framework: action composition, routing, template engine, async handling, Guice DI.

## Python

- [`django/`](./django/) — Django: app structure, models/views/serializers, middleware, signals, querysets, migrations.
- [`fastapi/`](./fastapi/) — FastAPI: route design, dependency injection, Pydantic schemas, async boundaries, background tasks.
- [`flask/`](./flask/) — Flask: blueprints, app factory, extensions, Flask globals, request lifecycle.
- [`tornado/`](./tornado/) — Tornado: async request handling, coroutines, WebSocket, non-blocking I/O.
- [`sanic/`](./sanic/) — Sanic: async request handling, blueprints, middleware, background tasks.
- [`falcon/`](./falcon/) — Falcon: RESTful resource design, middleware, hooks, content negotiation.

## JavaScript / TypeScript

- [`express/`](./express/) — Express: middleware pipeline, routing, error handling, async patterns, validation.
- [`nestjs/`](./nestjs/) — NestJS: modules, DI, decorators, guards, interceptors, pipes, filters.

## Ruby

- [`rails/`](./rails/) — Rails: model/view/controller, service objects, callbacks, background jobs, migrations.
- [`laravel/`](./laravel/) — Laravel: controllers, Eloquent, service providers, events, queues, policies.

## Go

- [`gin/`](./gin/) — Gin: handlers, middleware, routing, validation, context propagation.
- [`fiber/`](./fiber/) — Fiber: handlers, middleware, routing, error handling, validation.
- [`echo/`](./echo/) — Echo: handlers, middleware, routing, data binding, validation.

## Rust

- [`actix-web/`](./actix-web/) — Actix-web: actors, routing, middleware, extractors, error handling.
- [`axum/`](./axum/) — Axum: routing, extractors, middleware, tower service composition, error handling.
- [`rocket/`](./rocket/) — Rocket: routing, request guards, form/data handling, templating, error handling.

## Kotlin

- [`ktor/`](./ktor/) — Ktor: routing, plugins, content negotiation, DI, async request handling.

## Elixir

- [`phoenix/`](./phoenix/) — Phoenix: contexts, LiveView, PubSub, Ecto schemas, channels, real-time features.

## .NET

- [`aspnet-core/`](./aspnet-core/) — ASP.NET Core: middleware, DI, controllers/minimal APIs, EF Core, hosted services.
