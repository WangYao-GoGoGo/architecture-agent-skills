# Frontend Framework Skills

Frontend framework-specific skills live here when architecture depends on component lifecycle, rendering, state management, effects, routing, and data loading boundaries.

## React Ecosystem

- [`react/`](./react/) — React: components, hooks, state management, effects, context, rendering boundaries.
- [`nextjs/`](./nextjs/) — Next.js: server/client components, routing, data fetching, caching, server actions, API routes.
- [`remix/`](./remix/) — Remix: routing, loaders, actions, nested routes, error boundaries, data loading.
- [`preact/`](./preact/) — Preact: components, hooks, signals, state management, rendering performance.

## Vue Ecosystem

- [`vue/`](./vue/) — Vue: Composition API, reactivity, components, router, Pinia/Vuex state management.
- [`nuxt/`](./nuxt/) — Nuxt: auto-imports, modules, SSR/SSG, middleware, composables, server routes.
- [`alpinejs/`](./alpinejs/) — Alpine.js: directives, stores, data flow, AJAX patterns, component design.

## Angular Ecosystem

- [`angular/`](./angular/) — Angular: modules/standalone components, services, DI, RxJS, guards, interceptors.
- [`lit/`](./lit/) — Lit: web components, reactive properties, shadow DOM, events, lifecycle.
- [`stencil/`](./stencil/) — Stencil: web components, decorators, reactive properties, shadow DOM, events.

## Svelte Ecosystem

- [`svelte/`](./svelte/) — Svelte: reactivity, stores, components, lifecycle, transitions.
- [`sveltekit/`](./sveltekit/) — SvelteKit: routing, load functions, form actions, server/client boundaries, endpoints.

## Emerging Frameworks

- [`solidjs/`](./solidjs/) — Solid.js: signals, effects, stores, reactive primitives, resources.
- [`qwik/`](./qwik/) — Qwik: resumability, lazy loading, `$` conventions, serialization, stores.
- [`astro/`](./astro/) — Astro: islands architecture, content collections, server/client boundaries, integrations.

## Classic Frameworks

- [`ember/`](./ember/) — Ember.js: components, routes, services, controllers, Ember Data.
- [`mithril/`](./mithril/) — Mithril: components, routing, XHR, redraw system, state ownership.
- [`backbone/`](./backbone/) — Backbone.js: models, views, collections, routers, events.
