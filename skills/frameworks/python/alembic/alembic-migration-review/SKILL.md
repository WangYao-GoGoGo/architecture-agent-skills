# Alembic Migration Review

## When To Use

- The main decision is about Alembic migration versioning, autogenerate review, rollout strategy, or backfill design.
- Reviewing downgrade behavior, data migration safety, or deployment compatibility.

## Workflow

1. Identify the migration versioning scheme — naming, ordering, and branching.
2. Review autogenerated migrations manually — are detected changes correct and complete?
3. Check rollout strategy — expand/migrate/contract pattern for zero-downtime.
4. Review backfill scripts — are data migrations separated from schema changes?
5. Check downgrade or forward-fix behavior — is rollback defined and tested?
6. Review migration testing — representative schema and data, lock risk analysis.
7. Recommend the smallest structural change that improves migration safety.

## Output Format

```markdown
Alembic migration review:
- Versioning scheme:
- Autogenerate review:
- Rollout strategy:
- Backfill design:
```
