# Core Knowledge

Architecture-level heuristics for fundamental design and review skills. These cards support the core skills in `skills/core/`.

## Cards

- `architecture-decision-review/` — Decision governance, ADR structure, tradeoff analysis.
- `dependency-boundary-review/` — Dependency direction, coupling, ownership, stable vs volatile dependencies.
- `refactoring-planner/` — Behavior-preserving refactoring, incremental change, migration safety.
- `anti-overengineering-review/` — Complexity cost, abstraction rent, YAGNI, simplest workable design.
- `architecture-before-coding/` — Responsibility mapping, boundary definition, pattern selection, design sketch.
- `design-pattern-selector/` — Pattern pressure identification, decision table, anti-pattern warnings.
