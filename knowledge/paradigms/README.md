# Paradigm Knowledge

Reusable concepts for programming paradigms.

- `object-oriented/` — OO design heuristics, SOLID, encapsulation, polymorphism, common risks
- `procedural/` — procedural design heuristics, module boundaries, data flow, side-effect isolation
- `functional/` — functional composition, purity, immutability, algebraic data types
- `systems-oriented/` — systems boundary design, resource ownership, error handling, concurrency
- `cross-paradigm/` — paradigm comparison table, decision heuristics, mixed-paradigm guidance
