# Object-Oriented Design

## Core Idea

Object-oriented design organizes behavior around objects that own state, rules, and collaborations.

## Useful For

- Domain concepts with behavior and invariants.
- Variation handled through polymorphism.
- Encapsulating mutable state.

## Risks

- God classes.
- Inheritance where composition would be clearer.
- Interface-heavy designs without real substitution needs.
