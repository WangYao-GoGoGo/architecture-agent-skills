# Decision Governance

Architecture governance cards describe how teams record, evaluate, and evolve architecture decisions.

## Structure

- `records/`: ADRs and architecture RFCs.
- `validation/`: fitness functions and architecture checks.
- `review-process/`: review checklists, technical radar, and architecture principles.

## Fit Rule

Governance should be lightweight and useful. Add process only when it helps teams make better decisions, preserve context, or catch architecture drift.
