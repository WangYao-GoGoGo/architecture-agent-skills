# Technical Radar

## Project Fit

Technical radar fits teams that need a shared view of adopted, trial, hold, and deprecated technologies or patterns.

## Use When

- Many teams choose frameworks, databases, libraries, or patterns independently.
- The organization wants lightweight guidance without blocking all experimentation.

## Avoid When

- The project is small enough that a simple README is enough.
- Radar entries are not maintained and become stale.

## Core Idea

A technical radar records guidance about technologies and practices: adopt, trial, assess, or hold.

## Fits Best With

- Framework choices, database technologies, architecture patterns, testing tools, deployment platforms.

## Verification

- Entries have owners and review dates.
- Guidance is tied to real experience.
- Teams can request changes based on evidence.
