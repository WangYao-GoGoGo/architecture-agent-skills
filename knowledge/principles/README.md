# Principles

Principle cards provide reusable architecture heuristics for skills.

- `solid.md`: object-oriented responsibility and dependency principles.
- `grasp.md`: responsibility assignment heuristics.
- `dependency-inversion.md`: dependency direction and abstraction boundaries.
- `separation-of-concerns.md`: separating reasons to change.
- `coupling-and-cohesion.md`: evaluating module shape.
