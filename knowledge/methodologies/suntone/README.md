# Suntone Architecture Methodology

This folder is reserved for Suntone-style architecture learning notes or terminology mapping.

## How To Use This Folder

- Capture the source's learning path, terminology, and decision framework.
- Link each reusable concept to its canonical card in `knowledge/`.
- Avoid copying long course text or proprietary material.

## Suggested Mapping

- Object responsibility and OO design: `knowledge/paradigms/object-oriented/`
- SOLID and GRASP: `knowledge/principles/`
- Design patterns: `knowledge/patterns/`
- Application structure: `knowledge/architecture/application-styles/`
- Java-specific implementation: `knowledge/languages/java/` and `knowledge/frameworks/java/`
