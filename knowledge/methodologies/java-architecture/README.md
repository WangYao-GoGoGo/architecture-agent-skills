# Java Architecture Methodology

This folder maps Java architecture learning paths to reusable knowledge cards.

## Suggested Mapping

- Java language idioms: `knowledge/languages/java/`
- Java frameworks: `knowledge/frameworks/java/`
- Object-oriented principles: `knowledge/principles/` and `knowledge/paradigms/object-oriented/`
- Design patterns: `knowledge/patterns/`
- Application styles: `knowledge/architecture/application-styles/`
- Database and transaction concerns: `knowledge/data-systems/`

## Placement Rule

Keep Java-specific mechanics here only when they are about a learning path or methodology. Put reusable Java architecture idioms in `knowledge/languages/java/`.
