# Methodologies And Schools

This folder captures named learning systems, architecture curricula, and source-oriented knowledge maps.

Use this folder when the project needs to preserve a named body of knowledge such as Suntone architecture learning notes, Java architecture curricula, or GoF pattern source mapping.

## Placement Rule

- Put reusable concepts in their natural homes: `principles/`, `patterns/`, `architecture/`, `languages/`, `frameworks/`.
- Put source-specific organization, reading order, terminology mapping, and curriculum notes here.
- Avoid duplicating full concept explanations here when a reusable card already exists elsewhere.
