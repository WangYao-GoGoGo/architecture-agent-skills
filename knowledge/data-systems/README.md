# Data Systems Knowledge

Reusable data-system architecture concepts for skills.

- `core/`: access patterns, consistency, migrations, indexing, and general caching.
- `relational/`: relational schema, constraints, joins, and transactions.
- `document/`: document model aggregates, embedding, and references.
- `key-value/`: key design, TTLs, hot keys, and source-of-truth boundaries.
- `graph/`: graph traversal and relationship modeling.
- `search/`: search index, relevance, and freshness concerns.
- `vector/`: embeddings, chunking, vector search, and retrieval quality.
- `cache/`: cache store and invalidation concerns.
- `column-family/`: wide-column and column-family modeling concerns.
- `technologies/`: technology-specific database knowledge.
