# Backend Framework Knowledge

Backend framework cards cover request lifecycle, routing, dependency injection, validation, persistence boundaries, background jobs, configuration, and observability.

## Java / JVM

- [`spring-boot/`](./spring-boot/) — Spring Boot: controllers, services, domain logic, transactions, configuration, auto-configuration.
- [`micronaut/`](./micronaut/) — Micronaut: AOT compilation, DI scopes, reactive types, configuration, native-image.
- [`quarkus/`](./quarkus/) — Quarkus: CDI beans, reactive messaging, Panache ORM, extensions, native-image.
- [`vertx/`](./vertx/) — Vert.x: verticle design, event bus, reactive streams, shared data, failure handling.
- [`play/`](./play/) — Play Framework: controllers, action composition, execution contexts, templates, Guice.

## Python

- [`django/`](./django/) — Django: views, models, serializers, querysets, migrations, transactions.
- [`fastapi/`](./fastapi/) — FastAPI: routers, Pydantic schemas, DI, async I/O, startup/shutdown lifecycle.
- [`flask/`](./flask/) — Flask: blueprints, app factory, extensions, globals, configuration.
- [`tornado/`](./tornado/) — Tornado: async handlers, coroutines, WebSocket, IOLoop, blocking I/O.
- [`sanic/`](./sanic/) — Sanic: blueprints, handlers, middleware, async boundaries, background tasks.
- [`falcon/`](./falcon/) — Falcon: resources, hooks, middleware, error handling, content negotiation.

## JavaScript / TypeScript

- [`express/`](./express/) — Express: middleware, routing, error handling, async patterns, validation.
- [`nestjs/`](./nestjs/) — NestJS: modules, DI, decorators, guards, interceptors, pipes, filters.

## Ruby

- [`rails/`](./rails/) — Rails: controllers, models, callbacks, jobs, migrations, service objects.
- [`laravel/`](./laravel/) — Laravel: controllers, Eloquent, service container, events, queues, policies.

## Go

- [`gin/`](./gin/) — Gin: handlers, middleware, context, validation, error handling.
- [`fiber/`](./fiber/) — Fiber: handlers, middleware, Ctx, validation, error handling.
- [`echo/`](./echo/) — Echo: handlers, middleware, binding, validation, error handling.

## Rust

- [`actix-web/`](./actix-web/) — Actix-web: handlers, middleware, extractors, error handling, async boundaries.
- [`axum/`](./axum/) — Axum: handlers, extractors, middleware, tower layers, error handling.
- [`rocket/`](./rocket/) — Rocket: routes, guards, data types, Responder, templates.

## Kotlin

- [`ktor/`](./ktor/) — Ktor: routes, plugins, content negotiation, DI, async handling.

## Elixir

- [`phoenix/`](./phoenix/) — Phoenix: contexts, LiveView, PubSub, Ecto, channels.

## .NET

- [`aspnet-core/`](./aspnet-core/) — ASP.NET Core: middleware, DI, controllers, EF Core, hosted services, configuration.
