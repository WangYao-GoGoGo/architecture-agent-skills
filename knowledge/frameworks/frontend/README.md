# Frontend Framework Knowledge

- [`frontend-frameworks.md`](./frontend-frameworks.md): lifecycle, rendering, state, effects, routing, and data loading boundaries.

## React Ecosystem

- [`react/`](./react/) — React: components, hooks, state, effects, context, rendering.
- [`nextjs/`](./nextjs/) — Next.js: server/client components, routing, data fetching, caching, server actions.
- [`remix/`](./remix/) — Remix: routing, loaders, actions, nested routes, error boundaries, caching.
- [`preact/`](./preact/) — Preact: components, hooks, signals, state, rendering.

## Vue Ecosystem

- [`vue/`](./vue/) — Vue: Composition API, reactivity, components, stores, watchers.
- [`nuxt/`](./nuxt/) — Nuxt: auto-imports, modules, server/client boundaries, composables, plugins.
- [`alpinejs/`](./alpinejs/) — Alpine.js: directives, stores, data flow, AJAX, components.

## Angular Ecosystem

- [`angular/`](./angular/) — Angular: modules, components, services, DI, RxJS, guards.
- [`lit/`](./lit/) — Lit: web components, reactive properties, shadow DOM, events, lifecycle.
- [`stencil/`](./stencil/) — Stencil: web components, decorators, reactive properties, shadow DOM, events.

## Svelte Ecosystem

- [`svelte/`](./svelte/) — Svelte: reactivity, stores, components, lifecycle.
- [`sveltekit/`](./sveltekit/) — SvelteKit: routing, load functions, form actions, server/client boundaries.

## Emerging Frameworks

- [`solidjs/`](./solidjs/) — Solid.js: signals, effects, stores, memos, resources.
- [`qwik/`](./qwik/) — Qwik: resumability, `$` conventions, serialization, stores, resources.
- [`astro/`](./astro/) — Astro: islands, content collections, server/client boundaries, integrations.

## Classic Frameworks

- [`ember/`](./ember/) — Ember.js: components, routes, services, controllers, Ember Data.
- [`mithril/`](./mithril/) — Mithril: components, routing, XHR, redraw system.
- [`backbone/`](./backbone/) — Backbone.js: models, views, collections, routers, events.
